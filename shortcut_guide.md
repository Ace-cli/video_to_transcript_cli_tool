# IDE Navigation & Shortcut Guide (Linux)

This guide compares essential navigation and code management shortcuts for **VS Code** and **PyCharm** on Linux.

## 🚀 Navigation & Movement

| Action | VS Code | PyCharm |
| :--- | :--- | :--- |
| **Go to Definition** | `F12` or `Ctrl + Click` | `Ctrl + B` or `Ctrl + Click` |
| **Peek Definition** | `Alt + F12` | `Ctrl + Shift + I` |
| **Navigate Back** | `Ctrl + Alt + -` (or `Alt + ←`) | `Ctrl + Alt + ←` |
| **Navigate Forward** | `Ctrl + Shift + -` (or `Alt + →`) | `Ctrl + Alt + →` |
| **Go to Line** | `Ctrl + G` | `Ctrl + G` |
| **Last Edit Location** | `Ctrl + K`, `Ctrl + Q` | `Ctrl + Shift + Backspace` |
| **Go to Matching Bracket**| `Ctrl + Shift + \` | `Ctrl + Shift + M` |

## 📂 Search & Exploration

| Action | VS Code | PyCharm |
| :--- | :--- | :--- |
| **Go to File** | `Ctrl + P` | `Ctrl + Shift + N` |
| **Search Everywhere** | `Ctrl + Shift + F` (Search in files) | `Shift` (Press twice) |
| **Go to Symbol (File)** | `Ctrl + Shift + O` | `Ctrl + F12` |
| **Go to Symbol (Project)**| `Ctrl + T` | `Ctrl + Alt + Shift + N` |
| **Find Usages** | `Shift + F12` | `Alt + F7` |
| **Show Call Hierarchy** | `Shift + Alt + H` | `Ctrl + Alt + H` |

## 📐 Code Folding & Formatting

| Action | VS Code | PyCharm |
| :--- | :--- | :--- |
| **Collapse All** | `Ctrl + K`, `Ctrl + 0` | `Ctrl + Shift + -` (Numpad or Standard) |
| **Expand All** | `Ctrl + K`, `Ctrl + J` | `Ctrl + Shift + +` (Numpad or Standard) |
| **Collapse Region** | `Ctrl + Shift + [` | `Ctrl + -` |
| **Expand Region** | `Ctrl + Shift + ]` | `Ctrl + +` |
| **Format Document** | `Ctrl + Shift + I` | `Ctrl + Alt + L` |
| **Optimize Imports** | `Shift + Alt + O` | `Ctrl + Alt + O` |

## 💻 Window & Editor Management

| Action | VS Code | PyCharm |
| :--- | :--- | :--- |
| **Split Editor** | `Ctrl + \` | `Right Click Tab` > Split |
| **Toggle Sidebar** | `Ctrl + B` | `Alt + 1` |
| **Focus Terminal** | `Ctrl + ` ` (backtick) | `Alt + F12` |
| **Command Palette** | `Ctrl + Shift + P` | `Ctrl + Shift + A` |
| **Rename Symbol** | `F2` | `Shift + F6` |

> **Note:** Keybindings may vary slightly depending on your specific Linux window manager or if you have customized keymaps installed (e.g., using the IntelliJ Keymap in VS Code).
